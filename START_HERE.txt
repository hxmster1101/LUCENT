LUCENT BOT - START HERE

1) Upload ALL files/folders in this folder to the GitHub repository.
2) Railway -> Deploy from GitHub.
3) Railway -> Variables -> add:
   DISCORD_TOKEN = your Discord bot token
4) Redeploy.
5) Do NOT paste the token into index.js.
6) If the bot is only in one server, slash commands are registered to that server automatically.
7) In Discord, use /setup.

Discord Developer Portal:
- Bot -> Privileged Gateway Intents:
  Server Members Intent = ON
  Message Content Intent = ON
- Invite scopes: bot + applications.commands
- For easiest setup, give the bot Administrator permission.

Railway:
- package.json already has "start": "node index.js"
- .nvmrc + package.json force Node 24.17.0, so the old Node 18 shown in the previous deployment should not be used by this new project.

Important:
- /storeadd updates the store message immediately.
- /gachasetup automatically creates/updates the Gacha Ticket product at 5 Coins.
- Data is stored in data/lucent.sqlite.
- For persistent data across Railway redeploys, attach a Railway Volume mounted at /app/data.
